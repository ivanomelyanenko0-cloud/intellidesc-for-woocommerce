WordPress 7.0 is scheduled for release on May 20, 2026. Are your plugins ready?

After testing your plugins and confirming compatibility, please update the "Tested up to" value in your plugin's readme.txt file to 7.0. This small update helps users trust your plugin's compatibility and encourages them to update.

Key updates plugin developers should know about:

  - WordPress 7.0 includes a fresh coat of paint in the admin with `Modern` being the new default admin theme. Every screen has seen some sort of update including those that use `@wordpress/components` so please check and ensure everything looks great with this update!

  - Work continues towards the editor always being served inside an iframe. You may need to update your plugin to ensure no future issues.
    https://make.wordpress.org/core/2026/02/24/iframed-editor-changes-in-wordpress-7-0/

  - Support for PHP 7.2 and 7.3 has been dropped. Note that the minimum recommended version of PHP remains 8.3, but the new minimum supported version is 7.4.
    https://make.wordpress.org/core/2026/01/09/dropping-support-for-php-7-2-and-7-3/

  - The new AI Client adds a provider-agnostic PHP API that lets plugins send prompts to AI models and receive results through a consistent interface.
    https://make.wordpress.org/core/2026/03/24/introducing-the-ai-client-in-wordpress-7-0/

  - A new Connections Screen allows for central management of API keys used across plugins.
    https://make.wordpress.org/core/2026/03/18/introducing-the-connectors-api-in-wordpress-7-0/

  - The Abilities API introduced in WP 6.9 was extended to provide a counterpart JavaScript API for implementing client-side abilities.
    https://make.wordpress.org/core/2026/03/24/client-side-abilities-api-in-wordpress-7-0/

  - PHP-only block registration means that Simple blocks can now be created using only PHP.
    https://make.wordpress.org/core/2026/03/03/php-only-block-registration/

Complete details are available in the full WordPress 7.0 Field Guide:
https://make.wordpress.org/core/2026/05/14/wordpress-7-0-field-guide/


*Have you evaluated your plugins with Plugin Check yet?*

Plugin Check helps you spot common technical issues in your plugin so you can improve it. Simply install it as a plugin on your WordPress site, select the plugin you want to check, and review the report to identify and resolve any issues.

Soon, Plugin Check will also scan your plugin updates on WordPress.org and email you if any issues are found by it. Prepare ahead of time by using Plugin Check – or other code review tools – before updating.

Learn more: https://wordpress.org/plugins/plugin-check/


*How to test and update your plugins*

Test with the latest Release Candidate using the WordPress Beta Tester plugin:
https://wordpress.org/plugins/wordpress-beta-tester/

Once confirmed that your plugin is compatible, update your readme.txt file (in the stable tag directory) to include: Tested up to: 7.0


You will find below the current "Tested up to" values for each of your plugins:

 * https://wordpress.org/plugins/intellidesc-for-woocommerce/ (tested up to 6.9.4)

Plugins not marked as compatible with one of the last three major WordPress releases will display a warning on the plugin page. Avoid this by keeping the "Tested up to" value current.

No longer maintaining your plugin? Here's how to close it:
https://developer.wordpress.org/plugins/wordpress-org/plugin-developer-faq/#how-do-i-close-my-plugin
